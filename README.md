## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher.
- Built-in standard modules only (`heapq`, `collections`, `itertools`, `math`). No external packages or `pip install` required.

### Clone & Execution

```bash
# Clone the repository
git clone https://github.com/sumit-kumar-sahu-051/AI_LAB_25CSEAIML051.git

# Navigate into the project directory
cd AI_LAB_25CSEAIML051

# Run any experiment
python BFS.py
```
